# MeshCraft 用户手册

## 1. 简介

MeshCraft 是一款基于浏览器的高性能 3D 网格编辑器，使用 React、TypeScript、React Three Fiber、Three.js、TailwindCSS 和 Zustand 构建。它以轻量级 DCC（Digital Content Creation）工具为设计目标，提供实时模型查看、变换编辑、PBR 材质调节、glTF / GLB 资产导入审查以及丰富的视口渲染能力。

**适用人群：**

- **3D 美术师**：快速预览和调整模型材质
- **前端开发者**：检查 glTF 资产并调试渲染效果
- **设计师**：在浏览器中进行轻量 3D 编辑
- **学生与爱好者**：学习 3D 渲染管线和 WebGL 技术

**核心能力：**

- 程序化演示场景与 LOD 系统
- glTF / GLB 资产导入（支持 Draco 压缩）
- 对象变换编辑（平移 / 旋转 / 缩放）
- PBR 材质实时编辑
- 纹理槽查看与替换
- 多种着色模式和视觉效果
- 项目快照保存与恢复
- 场景导出为 GLB

## 2. 系统要求

| 类别 | 最低要求 | 推荐配置 |
|------|---------|---------|
| 浏览器 | Chrome 90+、Edge 90+、Firefox 90+ | Chrome / Edge 最新稳定版 |
| 图形 API | WebGL 2.0 | WebGL 2.0 |
| GPU | 支持 WebGL 2.0 的集成显卡 | 独立显卡或 Apple Silicon |
| 开发环境 | Node.js 18+ | Node.js 20+ |
| 屏幕分辨率 | 1280 × 720 | 1920 × 1080 |

> [!NOTE]
> MeshCraft 会自动将设备像素比（DPR）上限设为 2，以在高分屏上平衡画质与性能。

## 3. 快速开始

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

启动后，终端会输出本地访问地址（默认为 `http://localhost:5173`），在浏览器中打开即可进入编辑器。

### 首次启动

编辑器启动后会自动加载程序化演示场景 **TurbineAssembly**，包含 4 个网格对象和 3 个 PBR 材质，可以直接开始探索各项功能。

### 生产构建

```bash
npm run build
```

构建产出位于 `dist/` 目录下，可直接部署到任意静态服务器。

### 运行测试

```bash
npm test
```

使用 Vitest 运行项目测试套件。

> [!TIP]
> 发布新版本前，建议先运行 `npm test` 和 `npm run build` 确保无错误。

## 4. 界面概览

MeshCraft 采用经典的 DCC 工具布局，分为五个主要区域：

### 顶部工具栏

从左到右依次是：

- **MeshCraft 标识**：项目名称与图标
- **项目操作**：新建（New）、打开（Open）、保存（Save）、导入（Import）
- **模式切换**：Object（对象）/ Material（材质）/ Render（渲染）/ Analyze（分析）
- **状态信息区**：导入状态指示、未保存提示（Unsaved / Saved）、已导入资产名称、FPS 计数器
- **导出按钮**：Export GLB

### 左侧面板 — 场景大纲

显示完整的场景层级树结构，节点类型包括：

| 图标类型 | 含义 |
|---------|------|
| 组（Group） | 容器节点，可展开/折叠 |
| 网格（Mesh） | 几何体对象，显示三角面数 |
| 材质（Material） | PBR 材质节点 |
| 纹理（Texture） | 贴图资源 |
| 灯光（Light） | 光源 |
| 摄像机（Camera） | 相机节点 |

点击节点即可选中对应对象，面板底部显示场景总三角面数汇总。

- **Tab 视图**：支持 `Scene / Assets / Materials` 三种筛选视图。
- **搜索过滤**：支持按节点名称搜索，并保留匹配节点的父级层级关系。

### 中央视口

3D 渲染画布，支持：
- 轨道式相机导航
- 变换 Gizmo 操作
- 选中对象高亮显示
- XYZ 轴颜色指示器
- 文件拖放导入区域
- 视口信息叠加层

### 右侧面板 — Inspector 检查器

分为以下可折叠区块：

- **Transform**：位置（Position）、旋转（Rotation）、缩放（Scale）的 XYZ 数值输入
- **Material**：Base Color 拾色器、Metalness、Roughness、Emission、Opacity 滑块
- **Textures**：纹理通道列表，支持替换与重置
- **Selection**：当前选中节点名称、ID、绑定材质
- **Display**：着色模式和各类显示开关
- **Performance**：实时性能统计

### 底部状态栏

显示运行时诊断信息，包括 FPS、三角面数、Draw Calls、实例数等关键指标。

## 5. 视口导航

| 操作 | 功能 |
|------|------|
| 左键拖拽 | 环绕旋转相机 |
| 右键拖拽 | 平移相机 |
| 滚轮 / 触控板缩放 | 推拉缩放 |

**相机约束参数：**

- 最小距离：3 个单位
- 最大距离：18 个单位
- 最大仰角：约 100°（`π / 1.8` 弧度）
- 轨道中心：`(0, 0.6, 0)`
- 启用阻尼（Damping Factor: 0.08）

**自动旋转**：可在右侧 Inspector 的 Display 区块中开启 Auto Rotate，相机将自动绕轨道中心旋转。

## 6. 程序化演示场景

编辑器启动时默认加载 **TurbineAssembly** 场景——一个程序化生成的涡轮组件，用于展示编辑器的各项功能。

### 网格对象

| 对象名称 | ID | 三角面数 |
|---------|-----|---------|
| Housing_Shell | mesh-housing | 184,320 |
| Core_Rotor | mesh-core | 96,204 |
| Intake_Vents | mesh-vents | 42,880 |
| Fastener_Array | mesh-bolts | 18,752 |

### 材质

| 材质名称 | ID | 特点 |
|---------|-----|------|
| Brushed_Steel | mat-steel | 拉丝钢，高金属度 (0.86)，中低粗糙度 (0.34) |
| Carbon_Weave | mat-carbon | 碳纤维编织，高金属度 (0.85)，低粗糙度 (0.30) |
| Emissive_Trim | mat-glow | 自发光装饰，高 Emission (2.4)，青色光效 |

### 转子动画

Core_Rotor 具有持续旋转动画，在视口中可直观观察动态效果。

### LOD 系统

程序化场景支持 3 级 LOD（Level of Detail）自动切换：

| LOD 级别 | 触发距离 | 说明 |
|---------|---------|------|
| High（高） | < 7 | 完整细节 |
| Medium（中） | 7 – 14 | 中等细节 |
| Low（低） | ≥ 14 | 简化细节 |

相机距离变化时，系统自动在这三个层级之间切换，无需手动操作。

## 7. 导入 3D 资产

### 支持格式

- `.glb`（二进制 glTF）
- `.gltf`（JSON 格式 glTF）

### 导入方式

1. **文件选择器**：点击顶部工具栏的 **Import** 按钮，选择文件
2. **拖放导入**：将文件直接拖入视口区域

### Draco 压缩支持

MeshCraft 内置 Draco 解码器（位于 `public/draco` 目录），可自动解码经 Draco 压缩的 glTF 资产。

### 导入流程

```
文件读取 → glTF 解码 → 场景克隆 → 场景分析 → 树节点生成
→ 材质提取 → 纹理槽映射 → 变换注册 → 性能指标采集
```

### 导入状态指示

工具栏右侧会显示当前导入状态：

| 状态 | 含义 |
|------|------|
| No import | 未导入任何资产 |
| Decoding… | 正在解码和加载中（带旋转动画） |
| Ready: {文件名} | 导入成功，资产就绪 |
| Error: {信息} | 导入失败，附带错误描述 |

### 清除已导入资产

点击工具栏中显示的资产名称按钮即可卸载导入资产，编辑器将恢复到程序化演示场景。卸载时会自动释放相关 GPU 资源。

> [!WARNING]
> 清除导入资产后，所有对该资产的编辑（变换、材质修改等）都会丢失。

## 8. 变换编辑

### 切换 Gizmo 模式

在 Object 模式下，视口中会显示变换 Gizmo，共有三种模式：

- **Translate**（平移）：沿坐标轴移动对象
- **Rotate**（旋转）：绕坐标轴旋转对象
- **Scale**（缩放）：沿坐标轴缩放对象

### 使用视口 Gizmo

直接在视口中拖拽 Gizmo 的轴线或平面进行操作，颜色编码如下：

| 轴 | 颜色 |
|-----|------|
| X 轴 | 🔴 红色 |
| Y 轴 | 🟢 绿色 |
| Z 轴 | 🔵 蓝色 |

### 使用 Inspector 数值输入

在右侧 Inspector 的 Transform 区块中，可以直接输入 Position、Rotation、Scale 的 XYZ 精确数值。

### 适用范围

变换编辑适用于：
- 程序化场景的网格对象（`mesh-housing`、`mesh-core`、`mesh-vents`、`mesh-bolts`）
- 导入资产的根节点（`imported-root`）
- 导入资产的可变换子节点

> [!NOTE]
> 选中材质、纹理、灯光等非几何节点时，Transform 区块会显示提示信息，不可编辑。

## 9. 材质编辑

### 选择材质

可通过以下方式激活材质编辑：
- 在场景大纲中点击材质节点（如 Brushed_Steel）
- 在视口中点击绑定了材质的网格对象
- 点击导入资产中绑定了材质的子网格

### PBR 属性

| 属性 | 控件 | 取值范围 | 说明 |
|------|------|---------|------|
| Base Color | 拾色器 + 十六进制输入 | CSS 颜色值 | 基础颜色 |
| Metalness | 滑块 | 0 – 1 | 金属度，0 = 非金属，1 = 全金属 |
| Roughness | 滑块 | 0 – 1 | 粗糙度，0 = 光滑镜面，1 = 完全粗糙 |
| Emission | 滑块 | 0 – 4 | 自发光强度，> 0 时产生泛光效果 |
| Opacity | 滑块 | 0 – 1 | 不透明度，< 1 时自动启用透明模式 |

### 程序化与导入材质

程序化材质和导入材质均接入同一套编辑工作流。程序化材质的默认参数在材质库（Material Library）中预定义，修改后的值会被追踪并可保存到项目快照。

## 10. 纹理管理

### 查看纹理槽

选中导入材质后，Inspector 的 **Textures** 区块会列出所有已绑定的纹理槽，每个槽位显示：

- **通道名**：如 `map`、`normalMap`、`emissiveMap` 等
- **纹理名称**：贴图文件的显示名称
- **纹理 ID**：内部标识

### 替换纹理

每个纹理槽旁都有 **Replace** 按钮，点击后可选择本地图片文件覆盖原始纹理。

**支持的图片格式：**
- `.png`
- `.jpg` / `.jpeg`
- `.webp`

替换后，通道名旁会显示 **Override** 标记。

### 重置纹理

点击 **Reset** 按钮可撤销当前通道的纹理覆盖，恢复为原始纹理。

> [!NOTE]
> 纹理替换功能当前仅适用于导入材质。程序化材质的纹理通道暂不支持在 UI 中替换。

### 着色模式

|------|------|

| 开关 | 说明 | 默认 |

## 12. 导出场景

### 操作方式

点击顶部工具栏右侧的 **Export GLB** 按钮。

### 导出逻辑

- **有导入资产时**：导出导入资产的根节点及其子树
- **无导入资产时**：导出程序化演示场景

### 输出格式

二进制 glTF（`.glb`），MIME 类型为 `model/gltf-binary`。

### 文件命名规则

| 场景类型 | 输出文件名 |
|---------|-----------|
| 程序化场景 | `meshcraft-scene.glb` |
| 导入资产（如 `robot.glb`） | `robot-export.glb` |

> [!IMPORTANT]
> 当前导出以场景文件交付为主，不包含完整的编辑器会话状态。如需保存编辑进度，请使用项目快照功能。

## 13. 项目快照

### 保存

点击工具栏的 **Save** 按钮，编辑器会将当前完整状态序列化为 `.json` 文件（默认文件名：`meshcraft-project.json`）并触发下载。

**快照包含的内容：**

- 当前编辑器模式
- 选中对象状态
- 变换工具模式
- 程序化材质库参数
- 程序化对象变换
- 导入材质库参数
- 导入节点材质绑定
- 导入材质纹理槽信息
- 导入材质纹理覆盖记录
- 导入对象变换
- 场景树结构
- 所有显示开关设置
- 导入资产名称引用

### 打开

点击工具栏的 **Open** 按钮，选择之前保存的 `.json` 或 `.meshcraft` 文件，即可恢复编辑器状态。

### 新建项目

点击 **New** 按钮重置编辑器到初始状态。如果当前有未保存的更改，会弹出确认对话框。

### 未保存更改提示

工具栏中会显示 **Unsaved** / **Saved** 状态标记。关闭或刷新页面前，浏览器会提示确认，防止意外丢失编辑内容。

> [!WARNING]
> 项目快照不会嵌入外部导入的模型文件。恢复快照后，如果之前引用了导入资产，需要重新导入对应的 glTF / GLB 文件。

## 14. 编辑器模式

MeshCraft 提供四种工作模式，通过顶部工具栏中央的模式切换按钮切换：

| 模式 | 图标 | 用途 |
|------|------|------|
| Object | 📦 | 场景对象操作：选择、变换、层级管理 |
| Material | 🎨 | 材质编辑：PBR 参数调节、纹理管理 |
| Render | 📷 | 渲染预览：查看最终渲染效果 |
| Analyze | 📊 | 性能分析：查看渲染统计和诊断信息 |

> [!TIP]
> 在 Object 模式下才能使用变换 Gizmo。切换到其他模式后 Gizmo 会隐藏，但 Inspector 中的数值输入仍可使用。

## 15. 视觉效果指南

### 全息扫描外壳

基于自定义 GLSL 着色器实现，效果包含：

- **动态扫描线**：沿 Y 轴以 2.35 倍速运动的正弦波扫描
- **菲涅尔光晕**：基于视角和法线夹角的边缘泛光（Power: 2.8）
- **网格脉冲**：UV 空间的细密网格动画
- **青色辉光**：使用 `#39d8ff` 作为基础光色

整体透明度约 32%，通过扫描线和菲涅尔效应叠加动态变化。

### 实例化散布场

利用 `InstancedMesh` 技术，使用单次 Draw Call 渲染 1000 个粒子实例。粒子以环形分布在场景周围，每个实例拥有随机的位置、旋转和缩放。

### 后处理效果

启用 Post FX 后，视口会叠加以下后处理：

- **Bloom**（泛光）：高亮区域产生柔和光晕
- **Vignette**（暗角）：画面边缘渐暗，聚焦视觉中心

### LOD 切换

三级细节层次（详见第 6 节），根据相机与模型的距离自动无缝切换。

### HDR 环境光照

使用 `city` 预设的 HDR 环境贴图，提供基于图像的光照（IBL）和反射效果。

## 16. 性能监控

Inspector 的 **Performance** 区块提供实时渲染统计：

| 指标 | 含义 | 参考值 |
|------|------|--------|
| FPS | 每秒帧数 | ≥ 60 为稳定 |
| Triangles | 当前帧的三角面总数 | 视场景复杂度而定 |
| Instances | 实例化对象数量 | Scatter Field 开启时为 1000 |
| Draw Calls | 渲染调用次数 | 越低越好 |
| GPU Memory | GPU 显存估算 | 单位 MB |
| Decode | 资产解码耗时 | 单位 ms，仅导入时有意义 |
| Target | 帧率状态 | Stable（≥ 60）或 Warm（< 60）|

### 如何解读

- **FPS 持续低于 30**：考虑关闭 Scatter Field、Post FX 或降低场景复杂度
- **Draw Calls 过高**：检查是否导入了大量独立材质的模型
- **Decode 耗时过长**：原始资产可能过于庞大，建议优化后重新导入

### 优化建议

1. 关闭不需要的显示特效（Scatter Field、Hologram Scan、Post FX）
2. 使用 LOD Preview 检查简化效果
3. 导入前对资产进行 Draco 压缩
4. 避免单个文件超过 50 MB 的超大资产

## 18. 常见问题排查

### WebGL 不支持

**现象**：页面空白或提示 WebGL 不可用。

**解决方案**：
1. 确认浏览器版本满足最低要求（Chrome 90+、Edge 90+、Firefox 90+）
2. 在浏览器地址栏输入 `chrome://gpu` 检查 WebGL 2.0 是否启用
3. 更新显卡驱动
4. 避免使用无头浏览器或禁用 GPU 加速的配置

### 导入失败

**现象**：工具栏显示 `Error: Import failed` 或 `Error: Only .glb and .gltf files are supported`。

**解决方案**：
1. 确认文件扩展名为 `.glb` 或 `.gltf`
2. 检查文件是否损坏，可用其他 glTF 查看器验证
3. 如果使用 Draco 压缩，确认 `public/draco` 目录下的解码器文件完整
4. 查看浏览器控制台（F12）获取详细错误信息

### FPS 过低

**现象**：帧率持续低于 30，操作卡顿。

**解决方案**：
1. 在 Display 中关闭 Scatter Field 和 Post FX
2. 关闭 Hologram Scan
3. 切换着色模式为 Wireframe，排除材质复杂度问题
4. 检查导入资产的面数是否过高

### 视口黑屏

**现象**：视口区域全黑，无任何渲染内容。

**解决方案**：
1. 检查浏览器控制台是否有 WebGL context lost 错误
2. 刷新页面重试
3. 关闭其他占用 GPU 资源的标签页或应用
4. 重启浏览器

### 导入后模型不可见

**现象**：导入状态显示 Ready，但视口中看不到模型。

**解决方案**：
1. 模型尺度可能过大或过小，尝试在 Inspector 中调整 Scale
2. 模型可能偏离视口中心，检查 Position 并重置为 `(0, 0, 0)`
3. 确认模型包含可见的网格数据（而非仅有骨骼或空节点）

## 19. 技术说明

### WebGL 配置

- **电源偏好**：`powerPreference: "high-performance"`，优先使用独立 GPU
- **DPR 上限**：`Math.min(devicePixelRatio, 2)`，限制最大渲染分辨率
- **色调映射**：ACES Filmic Tone Mapping
- **颜色空间**：sRGB 输出
- **阴影**：PCF Soft Shadow Map
- **抗锯齿**：已启用
- **雾效**：线性雾，起始 18 个单位，结束 36 个单位

### 资源管理

- 导入资产卸载时，几何体（Geometry）、材质（Material）、纹理（Texture）均会被显式调用 `dispose()` 释放
- 纹理覆盖使用 Object URL，卸载时通过 `URL.revokeObjectURL()` 回收
- Draco 解码器在每次导入完成后会被正确释放

### 状态管理

- 使用 Zustand 管理全局编辑器状态
- 高频 3D 交互数据（如逐帧性能采样）尽量避免触发 React 重渲染
- 性能数据每 400ms 采样一次，减少状态更新频率

### 构建产出

- **three-stack chunk**：Three.js 及 React Three Fiber 相关依赖的打包产物，是最大的 chunk
- **icons chunk**：Lucide React 图标库的独立 chunk

## 20. 常见问答

**Q：MeshCraft 支持哪些 3D 文件格式？**
A：当前支持 `.glb` 和 `.gltf`（glTF 2.0 标准）。其他格式（如 `.obj`、`.fbx`）暂不支持。

**Q：能否同时导入多个模型？**
A：当前每次仅支持导入一个资产。导入新资产会替换当前已导入的资产。

**Q：导出的 GLB 文件包含哪些内容？**
A：导出包含可见的几何体、材质和纹理。编辑器内的效果（如 Hologram Scan、Scatter Field）不会包含在导出文件中。

**Q：项目快照文件可以与他人共享吗？**
A：可以共享 `.json` 快照文件，但需注意：如果快照引用了导入资产，对方需要自行拥有并重新导入相同的模型文件。

**Q：为什么修改材质后在导出文件中看不到变化？**
A：请确认材质编辑应用在了正确的材质槽上。导出时会使用当前视口中的材质状态。

**Q：MeshCraft 支持移动端浏览器吗？**
A：MeshCraft 需要 WebGL 2.0 支持，部分高端移动端浏览器可以运行，但界面和交互针对桌面端设计，移动端体验可能不佳。推荐使用桌面端浏览器。

**Q：如何贡献代码或反馈问题？**
A：请访问 GitHub 仓库 [HeyDYF/MeshCraft](https://github.com/HeyDYF/MeshCraft) 提交 Issue 或 Pull Request。
